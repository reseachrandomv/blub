# Blub 💙

A soft pastel-blue personal love site for **Ryu ♡ Lilu** (Blub).

Pure HTML / CSS / JS — no build step.

## Open locally

1. Open `index.html` in a browser, **or**
2. From this folder: `python3 -m http.server 8080` then visit `http://localhost:8080`

## GitHub Pages (repo: `blub` or `blub-love`)

Suggested owner: `reseachrandomv`

1. Create a new public repo named `blub` (or `blub-love`).
2. Upload the contents of this folder (not the parent zip) to the repo root — include `index.html`, `css/`, `js/`, `assets/`.
3. **Settings → Pages → Deploy from branch** → `main` / `/ (root)`.
4. Site will be at `https://reseachrandomv.github.io/blub/` (or `/blub-love/`).

Optional: add a custom domain later.
